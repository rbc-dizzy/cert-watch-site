Privacy policy
Private infrastructure monitoring

Know when certificates or services need attention.

CERT-WATCH is a personal monitoring tool used by its owner to check TLS certificates, certificate-renewal activity, and selected service health on servers and infrastructure the owner administers.

What CERT-WATCH does

  • Collects certificate metadata, expiry dates, certificate/key match results, and TLS endpoint checks.
  • Observes selected service states and certificate-renewal timers or job results.
  • Stores monitoring reports, history, and incident state locally on the owner's private NAS.
  • Is designed to send email alerts to the configured owner address when a monitored issue requires attention.

Google account access

Email notifications are planned but are not currently enabled. If enabled in the future, CERT-WATCH will use Google's Gmail API with the gmail.send permission solely to send monitoring notifications on the owner's behalf. It will not use this permission to read, search, modify, or delete Gmail messages.

Any OAuth credentials and refresh tokens used by CERT-WATCH are intended to be kept on the owner's NAS with access restricted to the system administrator. Monitoring data is not used for advertising, sold, or shared with data brokers.
